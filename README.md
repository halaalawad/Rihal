# Rihal | رِحال 

**Rihal** is an interactive game that introduces players to Saudi Arabia's cultural heritage through historical landmarks, local dialects, and traditional customs.

The journey begins in **Hail**, where players explore historical sites, learn local expressions, and complete interactive challenges inspired by Saudi heritage.
